Kettle

The Erica Synths LXR-02 drum machine, ported to the M-VAVE FM-1 as alternative firmware.

Try it in the browser Manual Library Files and source

Test release. Kettle has had very little testing on real FM-1s. If it crashes as it starts, the FM-1 can only be recovered with the FM-1-transporter (see the manual). You install it at your own risk; there is no warranty, and the authors accept no responsibility for damage to your FM-1.

Works in Chrome or Edge (Web MIDI). Connect the FM-1 directly to the computer with a USB data cable, close other apps that use MIDI, and allow MIDI (SysEx) when the browser asks. Don't unplug the cable or close this page while it writes.

1Check what your FM-1 runs

2Official V15 first

Install M-VAVE's official firmware V15 before installing Kettle for the first time. Kettle's package is built for V15's flash layout and update loader, and V15 is what you return to. If step 1 says your FM-1 already runs V15, skip to step 3.

Download the FM-1 firmware V15 from M-VAVE's download page, unpack it and select the unmodified FM-1.fwsc. This page checks the file in the browser (it is not uploaded anywhere) and only accepts the exact official V15 file.

The same button takes you back from Kettle to the official firmware. Kettle's projects are not kept: back them up first with the library page (Kettle 0.7 or later), and restore them there after installing Kettle again. Coming from Felucca, back up first with Felucca's page: V15 and Kettle both replace Felucca's saved data.

3Install Kettle

If an install is cut off (cable pulled, page closed), the FM-1 stays in update mode. Plug it in and press the same button again to finish it.
