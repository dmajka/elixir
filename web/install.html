Install Elixir

Put Elixir on your M-VAVE FM-1 over USB, from this page. Chrome or Edge (Web MIDI).

Test release. Elixir has had very little testing on real FM-1s. If it crashes as it starts, the FM-1 can only be recovered with the FM-1-transporter (see the manual). You install it at your own risk; there is no warranty, and the authors accept no responsibility for damage to your FM-1.

Connect the FM-1 directly to the computer with a USB data cable, close other apps that use MIDI, and allow MIDI (SysEx) when the browser asks. Don't unplug the cable or close this page while it writes.

1Check what your FM-1 runs

2Official V15 first

Install M-VAVE's official firmware V15 before installing Elixir for the first time. Elixir's package is built for V15's flash layout and update loader, and V15 is what you return to. If step 1 says your FM-1 already runs V15 or Elixir, skip to step 3.

Download the FM-1 firmware V15 from M-VAVE's download page, unpack it and select the unmodified FM-1.fwsc. This page checks the file in the browser (it is not uploaded anywhere) and only accepts the exact official V15 file.

The same button takes you back from Elixir to the official firmware. Elixir's projects are not kept: back them up first with the library page, and restore them there after installing Elixir again. Coming from Felucca, back up first with Felucca's page: V15 and Elixir both replace Felucca's saved data.

3Install Elixir

Installs Elixir on an FM-1 running V15 or Elixir. Updating Elixir keeps your projects, kit library and settings.

Elixir comes with the LXR-02's 85 factory kits built in (with Erica Synths' permission): turn PRESETS on the FM-1 to browse them. It can also put Hrtl's kit packs for the LXR-02 into your kit library once it is installed:


The two packs together fill about a quarter of the kit library's flash, each pack about 12%. They go into the library's first empty slots (L1 on); a kit already there is left alone, and you can save your own kits over these at any time. You can also add them later on the library page.

If an install is cut off (cable pulled, page closed), the FM-1 stays in update mode. Plug it in and press the same button again to finish it.
