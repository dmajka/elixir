Back up

Saves every project, and the session, to one file on this computer. Do this before installing other firmware (V15 or another): Elixir's own updates keep your projects, other firmware may not.

Restore

Puts a backup (or one project's file) back. The project that was in the slot before stays until the restore is complete, so an interrupted restore loses nothing.

Kit slots or the kit library?

Elixir keeps your kits in two places, both in the FM-1's flash. A third set, the LXR-02's 85 factory kits, is built into Elixir itself (from 0.19, with Erica Synths' permission): it takes none of this space and is always there.

  • The kit slots (64) belong to the project, like the LXR-02's. Patterns name their kit by slot number (a pattern whose Voices are KIT loads its kit), and the slots are saved with the project (SAVE → PROJECT, or AUTOSAVE's session). Loading another project brings its own 64 kits. Put a project's working kits here.
  • The kit library (128 kits, and 128 single sounds) is a collection of its own, written to flash at once and left as it is whatever project you load. Put kits you want in every project here, such as your favourites or Hrtl's kit packs (below). On the FM-1, turn PRESETS for the kit browser: it lists the factory kits (F1 …), then the library's (L1 …), then the slots; KNOB 1 jumps between them and OCT+ loads one. (CONFIG → BUTTONS & KITS, Kits first, puts the slots first.) A library kit can also be the morph target (LOAD → MORPH, From LIBRARY), and the sound browser on a track's sound pages offers single voices from its kits. To use a library kit with a pattern, load it and save it into a slot (SAVE → KIT, To SLOTS).

Picking a folder below takes the .SND files in it and in all its subfolders, nothing else: one project's folder (PROJ00 …), or an SD card's top folder for every project's kits, project by project. Chrome asks to "upload" the folder's files: the page only reads them here and sends the kits to your FM-1, nothing else leaves this computer. An LXR voice routed to the FX bus comes in as FX SEND 127 (the same sound); Elixir's own settings (sends, reverb, shaping, models) start at their defaults.

Kit library

Import LXR-02 kits into the library

Up to 128 kits, from the library kit you choose on; the rest are left out (the page says how many). The LXR-02's factory kits are already built into Elixir, so there is no need to import them.

Hrtl kit packs

Two sets of 16 kits by Hrtl for the LXR-02, distributed with Erica Synths' permission. They go into the library's first empty slots (L1 on, near the top of the kit browser's LIBRARY): a kit you keep there stays.

Both packs take about a quarter of the kit library's flash (each about 12%), leaving the rest for your own kits and sounds. You can save your own kits over them at any time.

In the library

On the FM-1, SAVE → KIT or MORPH with To LIBRARY saves into it, SAVE → SOUND a single sound. Click a kit to download it as an LXR-02 .SND file. Back the library up before installing other firmware; a backup restores onto any Elixir, the emulator's too.

    Empty the kit library

    Deletes every kit and sound in the library, for a clean start: installing V15 or updating Elixir doesn't clear it. The factory kits are built into Elixir and stay; the kit slots and projects aren't touched.

    Kit slots

    Import LXR-02 kits into the slots

    Up to 64 kits, from the slot you choose on, into the project that's playing. They replace the kits there until you load a project: save the project on the FM-1 (SAVE → PROJECT), or let AUTOSAVE keep them.

    Import an LXR-02 project

    Pick one project folder from an LXR-02 SD card (PROJ00 …), not the whole card: its kits go into the kit slots by their numbers (so each pattern still finds its kit), its patterns into Elixir's patterns, its songs into the songs. It replaces what's playing; save the project on the FM-1 afterwards. Elixir has 32 patterns to the LXR's 64: pick which half.

    A song's steps on a pattern from the other half play pattern 32 instead.

    The slots on the FM-1

    The playing project's 64 kits. Click one to download it as an LXR-02 .SND file (the LXR's parameters only: Elixir's own aren't in that format).
