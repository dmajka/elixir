Kettle library

Back up what's on your FM-1, put it back, and bring in kits from an LXR-02.

Install Try it in the browser Manual

Chrome or Edge (Web MIDI). Kettle 0.7 or later on the FM-1, connected with a USB data cable. Close other apps that use MIDI and allow MIDI (SysEx) when the browser asks.

Back up

Saves every project, and the session, to one file on this computer. Do this before installing other firmware (V15 or another): Kettle's own updates keep your projects, other firmware may not.

Restore

Puts a backup (or one project's file) back. The project that was in the slot before stays until the restore is complete, so an interrupted restore loses nothing.

Import LXR-02 kits

Pick .SND files from an LXR-02 SD card, or a whole project folder (PROJ00 …). They fill the kit slots of what's playing, from the first slot on. Then save the project on the FM-1 (SAVE → PROJECT), or let AUTOSAVE keep them in the session.

An LXR voice routed to the FX bus comes in as FX SEND 127 (the same sound). Kettle's own settings (sends, reverb, shaping, models) start at their defaults.

Import an LXR-02 project

Pick a project folder from an LXR-02 SD card (PROJ00 …): its kits go into the kit slots by their numbers (so each pattern still finds its kit), its patterns into Kettle's patterns, its songs into the songs. It replaces what's playing; save the project on the FM-1 afterwards. Kettle has 32 patterns to the LXR's 64: pick which half.

A song's steps on a pattern from the other half play pattern 32 instead.

Kit library

128 kits and 128 sounds the FM-1 keeps apart from the projects (SAVE → KIT or MORPH, To LIBRARY; SAVE → SOUND). They survive loading other projects; back them up here too.
