Chrome or Edge (Web MIDI). Kettle 0.7 or later on the FM-1, connected with a USB data cable. Close other apps that use MIDI and allow MIDI (SysEx) when the browser asks.

Back up

Saves every project, and the session, to one file on this computer. Do this before installing other firmware (V15 or another): Kettle's own updates keep your projects, other firmware may not.

Restore

Puts a backup (or one project's file) back. The project that was in the slot before stays until the restore is complete, so an interrupted restore loses nothing.

Kit slots or the kit library?

Kettle keeps kits in two places, both in the FM-1's flash:

  • The kit slots (64) belong to the project, like the LXR-02's. Patterns name their kit by slot number (with the pattern page's Kit change on AUTO, a pattern loads its kit), and the slots are saved with the project (SAVE → PROJECT, or AUTOSAVE's session). Loading another project brings its own 64 kits. Put a project's working kits here.
  • The kit library (128 kits, and 128 single sounds) is a collection of its own, written to flash at once and left as it is whatever project you load. Put kits you want in every project here, such as the LXR-02's factory kits or your favourites. On the FM-1, turn PRESETS to browse the slots and then the library (L1 …), and press OCT+ to load one. A library kit can also be the morph target (LOAD → MORPH, From LIBRARY), and the sound browser on a track's sound pages offers single voices from its kits. To use a library kit with a pattern, load it and save it into a slot (SAVE → KIT, To SLOTS).

Picking a folder below takes the .SND files in it and in all its subfolders, nothing else: one project's folder (PROJ00 …), or an SD card's top folder for every project's kits, project by project. Chrome asks to "upload" the folder's files: the page only reads them here and sends the kits to your FM-1, nothing else leaves this computer. An LXR voice routed to the FX bus comes in as FX SEND 127 (the same sound); Kettle's own settings (sends, reverb, shaping, models) start at their defaults.

Kit library

Import LXR-02 kits into the library

Up to 128 kits, from the library kit you choose on; the rest are left out (the page says how many). For example, pick the LXR-02 factory SD image's top folder to put all its kits (about 100, without the Init ones) in the library.

In the library

On the FM-1, SAVE → KIT or MORPH with To LIBRARY saves into it, SAVE → SOUND a single sound. Click a kit to download it as an LXR-02 .SND file. Back the library up before installing other firmware; a backup restores onto any Kettle, the emulator's too.

    Kit slots

    Import LXR-02 kits into the slots

    Up to 64 kits, from the slot you choose on, into the project that's playing. They replace the kits there until you load a project: save the project on the FM-1 (SAVE → PROJECT), or let AUTOSAVE keep them.

    Import an LXR-02 project

    Pick one project folder from an LXR-02 SD card (PROJ00 …), not the whole card: its kits go into the kit slots by their numbers (so each pattern still finds its kit), its patterns into Kettle's patterns, its songs into the songs. It replaces what's playing; save the project on the FM-1 afterwards. Kettle has 32 patterns to the LXR's 64: pick which half.

    A song's steps on a pattern from the other half play pattern 32 instead.

    The slots on the FM-1

    The playing project's 64 kits. Click one to download it as an LXR-02 .SND file (the LXR's parameters only: Kettle's own aren't in that format).
